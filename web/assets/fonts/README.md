# Book typefaces

The reading layout uses Source Sans 3 for prose and navigation, and Source Serif 4
for titles. Both are Adobe typefaces distributed under the SIL Open Font License;
the licenses are included alongside the fonts.

These Latin variable-font subsets were copied from
`@fontsource-variable/source-sans-3@5.3.1` and
`@fontsource-variable/source-serif-4@5.3.1`. They are served with the book so text
does not depend on a third-party font service. The italic Source Sans 3 face is
included for emphasis in prose. Mathematical type is provided by MathJax.
